Hidden Layer = 은닉층 = 중간층. 그러나 중간층 하나가 모델 전체는 아닙니다.

중간층의 뉴런 하나는 무엇을 하나?

입력에 가중치를 곱해 더한 뒤, 필요하면 ReLU 같은 활성화 함수를 적용합니다.

뉴런 입력값 = (온도 × 가중치) + (압력 × 가중치) + 편향
가상의 숫자 예제
(2 × 0.5) + (1 × −2) + 0 = −1
↓ ReLU 적용
max(0, −1) = 0

가중치

어떤 입력이 중요한지 정하는 연결 숫자. 학습하면서 수정됩니다.

편향(bias)

입력이 모두 0이어도 기준점을 옮길 수 있게 해주는 숫자.

활성화 함수

선형 계산만으로는 표현하기 어려운 복잡한 패턴을 만들도록 돕습니다.

5줄 코드로 히든층 만들기

PyTorch에서 입력 3개를 받아 히든 뉴런 4개를 거쳐 결과 2개를 계산합니다.

import torch.nn as nn
model = nn.Sequential(
    nn.Linear(3, 4),  # 입력 3개 → 중간 뉴런 4개
    nn.ReLU(),         # 음수 0, 양수 유지
    nn.Linear(4, 2))   # 양품·불량 점수 2개

Linear(3, 4)

입력 3개로 히든 뉴런 4개의 값을 계산합니다.

ReLU()

비선형 관계를 학습할 수 있도록 만듭니다.

Linear(4, 2)

히든층 결과 4개에서 클래스 점수 2개를 만듭니다.

강의 주석코드의 마지막은 Softmax 이전의 Logit입니다. 학습할 때 CrossEntropyLoss에 바로 넣기 위해 Softmax를 생략했습니다.
오늘의 한 문장Linear(3,4)와 ReLU가 한 개의 히든층 계산을 이룬다.

손실함수 · 0909

얼마나 틀렸을까? 오차를 숫자로 만들기

예측 2, 정답 1이므로 단순 오차는 1입니다. 학습에서는 오차를 손실로 표현합니다.

예제 손실함수 · 제곱오차의 1/2
L = ½ × (예측 − 정답)²
= ½ × (2 − 1)² = 0.5

왜 제곱할까?

양쪽 방향의 오차를 모두 양수로 계산하고 큰 오차에 더 큰 벌점을 주기 위해서입니다.

왜 1/2을 곱할까?

미분하면 앞의 2가 약분되어 계산이 간단해지기 때문입니다.

학습의 목표
손실 0.5 → 0에 가까워지도록 가중치를 수정
오늘의 한 문장손실함수는 “얼마나 틀렸는가”를 하나의 숫자로 표현한다.
AI 설계특론 · 기초 신경망
제곱오차는 여기서는 역전파 계산을 이해하기 위한 예제입니다. 실제 양품·불량 분류에서는 교차엔트로피 손실을 자주 씁니다.

연쇄법칙 · 1111

미분 계산: 왜 w₂는 2, w₁은 1일까?

출력에 가까운 가중치부터 앞쪽 가중치로 영향을 거슬러 계산합니다.

출력 쪽 w₂∂L/∂w₂

= (2 − 1) × 중간값 2
= 2

입력 쪽 w₁∂L/∂w₁

= 출력 오차 1 × w₂ 1 × 입력 1
= 1

일반화하면: ∂L/∂w₁ = (∂L/∂ŷ) × (∂ŷ/∂h) × (∂h/∂w₁)

이렇게 영향이 연결된 순서대로 곱해지는 규칙이 연쇄법칙(Chain Rule)입니다.
강의 주석이 수식은 앞서 정의한 L = ½(ŷ−y)², ŷ=x·w₁·w₂, x=1, w₁=2, w₂=1일 때 정확히 성립합니다.
오늘의 한 문장역전파의 수학적 핵심은 연쇄법칙이다.
AI 설계특론 · 기초 신경망

출력 확률 · 1515

ReLU 다음에는 Softmax가 무슨 일을 할까?

출력층의 점수(Logit)를 여러 클래스의 합이 100%인 값으로 바꿉니다.

양품 점수2.0
불량 점수1.0
↓
Softmax지수화 → 전체 합으로 나눔
양품73.1%
불량26.9%
P(양품) = e² / (e² + e¹) ≈ 0.731 · P(불량) ≈ 0.269
강의 주석Softmax 값은 합이 1인 모델 출력입니다. 반드시 현실에서 잘 보정된 확률이라는 뜻은 아닙니다. 분류 정확도 및 확률 보정(calibration)은 별도로 평가할 수 있습니다.
오늘의 한 문장Softmax는 점수를 여러 클래스에 대한 확률 형태로 변환한다.
AI 설계특론 · 기초 신경망
초보자에게 지수함수의 수학적 의미보다 “큰 점수에 더 높은 비율, 전체 합은 100%”라는 성질을 먼저 가르치세요.

둘은 비슷한 함수일까?

둘 다 숫자를 바꾸지만 사용 목적과 위치가 다릅니다.

구분ReLUSoftmax
주로 위치히든층분류 출력층

음수는 0으로, 양수는 그대로: max(0, x)

여러 점수 중 큰 점수에 상대적으로 높은 비중을 부여

오늘의 한 문장ReLU는 특징을 만들고 Softmax는 최종 점수를 분류 비율로 바꾼다.

질문: Softmax를 중간층에 넣는다면 불가능할까요? 수학적으로 불가능한 것은 아니지만 여기서는 전형적인 사용 위치를 설명한다는 점을 밝혀 주세요.
학습 코드 주의 · 1717

분류 모델은 어떻게 학습시키나?

PyTorch에서 CrossEntropyLoss는 Softmax 이전의 점수(Logit)를 받습니다.

학습할 때 · 권장 예

model = nn.Sequential(
    nn.Linear(3, 4),
    nn.ReLU(),
    nn.Linear(4, 2))

loss_fn = nn.CrossEntropyLoss()
logits = model(x)
loss = loss_fn(logits, y)

예측 확률을 보고 싶을 때

logits = model(x)
probs = logits.softmax(dim=1)

# [양품 확률, 불량 확률]
print(probs)
이진분류는 출력 1개 + Sigmoid + BCEWithLogitsLoss 방법도 사용할 수 있습니다.
강의 주석실제로 코드를 실행하려면 import torch 및 텐서 x, 정수 클래스 레이블 y의 정의가 추가로 필요합니다. 여기서는 핵심 학습 흐름만 보여줍니다.
오늘의 한 문장CrossEntropyLoss 앞에 Softmax를 중복 적용하지 않는다.
AI 설계특론 · 기초 신경망
초보자에게 매우 자주 발생하는 실수입니다. loss_fn(logits,y)와 probs=softmax(logits)를 분리해 설명해 주세요. 공식 문서: https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html
영상 모델 · 1818

그렇다면 CNN은 무엇인가?

CNN(합성곱 신경망)은 이미지의 작은 부분을 살펴보는 필터를 학습하는 신경망입니다.

웨이퍼 이미지
→
필터가 작은 영역을 훑음
→
선·모서리 등의 특징

CNN의 핵심

같은 필터를 이미지 여러 위치에 반복 사용하면서 국소적인 패턴을 찾아냅니다.

분류 모델

추출한 특징으로 양품·불량 점수를 계산합니다.

강의 주석웨이퍼 그림은 직접 그린 개념도입니다. 실제 검사의 광학·SEM 이미지 예시가 아닙니다.
오늘의 한 문장CNN은 사진 전체를 한 번에 외우는 대신 작은 영역의 특징을 조합해 이해한다.

필터는 학습되는 작은 가중치 배열이고, 필터가 지나가면서 특징맵(feature map)을 만든다고 설명하세요.
CNN 예제 · 1919

웨이퍼 균열은 단계적으로 발견됩니다

초기 층은 작은 선을, 뒤쪽 층은 여러 선이 모인 패턴을 다룰 수 있습니다.

1층

→

→

→
불량

출력

일반적인 순차형 CNN은 바로 앞 층의 특징맵을 다음 층으로 전달합니다.
강의 주석이러한 “선 → 형태 → 결함”의 계층적 설명은 직관을 위한 전형적인 사례이며, 실제 뉴런이 딱 이 의미만을 담당하는 것은 아닙니다.
오늘의 한 문장CNN의 깊은 층은 이전 층의 특징을 바탕으로 더 복잡한 패턴을 계산한다.

“처음의 선 정보가 반드시 사라진다”고 단정하지 마세요. 순차 구조에서는 처음 특징맵이 뒤층으로 직접 전달되지 않는다는 의미입니다.
DenseNet · 2020

DenseNet도 CNN입니다. 무엇이 다른가?

일반적인 순차형 CNN은 바로 앞 층을, DenseNet은 앞선 여러 층의 특징맵을 입력받습니다.

순차형 CNN

입력→1층→2층→3층

3층은 2층의 출력 특징맵을 직접 받습니다.

DenseNet의 Dense Block

입력1층2층3층

3층은 입력과 1·2층의 특징맵을 함께 받습니다.

강의 주석정확한 정의: Dense Block 안에서 같은 공간 크기의 모든 앞선 특징맵을 채널 축으로 이어 붙임(Concatenation). 일반적인 “더하기” 연결과 다릅니다.
오늘의 한 문장DenseNet은 앞선 특징을 계속 재사용하도록 연결을 조밀하게 만든 CNN이다.
AI 설계특론 · 기초 신경망
DenseNet이라는 이름의 Dense는 fully connected layer라는 뜻이 아닙니다. 2017년 CVPR Huang 외 연구가 제안한 연결 방식입니다.

오늘의 한 문장DenseNet은 앞선 층의 특징을 나중 층이 직접 참고할 수 있게 한다.

실제 성능 · 2222

DenseNet이 언제 유리하고, 언제 불리할까?

성능은 구조만으로 결정되지 않습니다. 정확도뿐 아니라 자원 비용도 검증해야 합니다.

기대할 수 있는 장점

  • 초기 층의 가느다란 선 특징을 뒤에서도 다시 활용
  • 중간 특징을 재사용해 정보 전달 경로 다양화
  • 역전파 기울기가 초기 층에 도달하기 유리한 경로 제공

놓치기 쉬운 한계

  • 특징맵을 이어 붙이므로 메모리·데이터 이동 부담 가능
  • 추론 속도가 언제나 빠르거나 정확도가 언제나 높은 것은 아님
  • 원본 이미지에 없는 균열 정보는 연결만으로 복구할 수 없음
