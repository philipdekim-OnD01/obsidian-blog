3. 주요 모델별 특성

각 모델의 그림은 실제 수식 전체가 아니라, 학생이 모델의 관점을 빠르게 잡기 위한 개념도이다.

KNN

거리 기반

핵심 생각: 서로 가까운 데이터는 비슷한 성질을 가진다.

  • 새 데이터 주변의 K개 이웃을 찾는다.
  • 이웃의 정답을 투표하거나 평균내어 예측한다.
  • 스케일 차이에 민감하므로 정규화가 중요하다.

선형회귀

선형 모델

핵심 생각: 결과값은 여러 입력 변수의 가중합으로 설명할 수 있다.

  • 연속형 숫자 예측에 사용한다.
  • 계수로 변수의 영향력을 해석하기 쉽다.
  • 복잡한 비선형 패턴에는 한계가 있다.

로지스틱 회귀

선형 분류

핵심 생각: 선형 모델의 결과를 확률로 바꾸어 분류한다.

  • 정상/불량, 합격/불합격 같은 이진 분류에 자주 사용한다.
  • 결과를 확률로 해석할 수 있다.
  • 복잡한 비선형 경계에는 한계가 있다.

나이브 베이즈

확률 기반

핵심 생각: 각 클래스에서 현재 데이터가 나왔을 가능성을 비교한다.

  • 베이즈 정리와 조건부 확률을 사용한다.
  • 특성들이 서로 독립이라고 단순하게 가정한다.
  • 텍스트 분류에서 빠르고 강한 기준 모델이 된다.

의사결정나무

규칙 기반

핵심 생각: 좋은 질문을 순서대로 던져 데이터를 나누면 예측할 수 있다.

  • 조건문을 따라가며 분류한다.
  • 해석이 쉽고 비선형 관계도 표현할 수 있다.
  • 너무 깊게 자라면 과적합이 발생한다.

SVM

마진 기반

핵심 생각: 단순히 나누는 선이 아니라 가장 여유 있게 나누는 경계를 찾는다.

  • 클래스 사이의 마진을 최대화한다.
  • 작은 데이터와 고차원 변수에서 강할 수 있다.
  • 커널을 쓰면 비선형 분류도 가능하다.

5. 손실함수와 경사하강법

손실함수는 모델의 예측이 실제 정답과 얼마나 다른지를 숫자로 표현한 것이다.

모델 학습은 보통 이 손실함수를 작게 만드는 방향으로 진행된다. 다만 모든 모델이 같은 방식으로 손실함수를 미분해 학습하는 것은 아니다.

모델대표 손실함수 또는 최적화 기준공식 또는 기준
KNN명시적 학습 손실함수 없음학습 단계에서 파라미터를 최적화하지 않는다.
선형회귀평균제곱오차, MSEL = (1/n) Σ(yi - ŷi)^2
로지스틱 회귀이진 교차엔트로피L = -(1/n) Σ [yi log(pi) + (1 - yi) log(1 - pi)]
나이브 베이즈음의 로그우도L = -Σ log P(yi | xi)
의사결정나무불순도 감소Gini = 1 - Σ pk^2
Entropy = -Σ pk log(pk)
SVM힌지 손실L = Σ max(0, 1 - yi(w·xi + b)) + λ||w||^2
오차를 줄임

선형회귀는 예측값과 실제값의 차이를 제곱해 평균한 값을 줄인다.

확률을 맞춤

로지스틱 회귀와 나이브 베이즈는 실제 정답에 높은 확률을 주도록 학습하거나 계산한다.

경계를 좋게 만듦

의사결정나무와 SVM은 각각 불순도 감소와 마진 위반 감소를 기준으로 분류 경계를 만든다.

로지스틱 회귀 손실함수 쉽게 읽기

이진 교차엔트로피는 실제 정답에 해당하는 확률만 골라서, 그 확률이 낮을수록 큰 벌점을 주는 손실함수이다.
정답이 불량이면 y = 1

공식 안에 y = 1을 넣으면 두 번째 항이 사라지고 -log(p)만 남는다.

L = -[1 log(p) + 0 log(1-p)] L = -log(p)

실제 불량일 때는 모델이 예측한 불량 확률 p가 높을수록 손실이 작다.

정답이 정상이면 y = 0

공식 안에 y = 0을 넣으면 첫 번째 항이 사라지고 -log(1-p)만 남는다.

L = -[0 log(p) + 1 log(1-p)] L = -log(1-p)

실제 정상일 때는 정상 확률 1-p가 높을수록 손실이 작다.

상황예측 확률손실 해석
실제 불량p = 0.9-log(0.9): 정답에 높은 확률을 주었으므로 손실이 작다.
실제 불량p = 0.1-log(0.1): 정답에 낮은 확률을 주었으므로 손실이 크다.
실제 정상p = 0.1-log(0.9): 정상 확률이 높으므로 손실이 작다.
실제 정상p = 0.9-log(0.1): 정상 확률이 낮으므로 손실이 크다.

Σ는 모든 데이터의 손실을 더한다는 뜻이고, 1/n은 데이터 개수로 나누어 평균 손실을 구한다는 뜻이다. 앞의 마이너스는 로그 확률이 음수이기 때문에 손실을 양수로 바꾸기 위해 붙는다.

확률 p는 어떻게 계산하는가?

로지스틱 회귀에서 확률 p는 사람이 직접 넣는 값이 아니라, 모델이 입력 데이터와 현재 가중치로 계산한 값이다.

입력 데이터
온도, 압력, 속도
→
점수 계산
z = w1x1 + w2x2 + ... + b
→
확률 변환
p = 1 / (1 + e^-z)
예시 z = 0.05×80 + (-0.8)×3 + 0.1×10 - 2 z = 0.6 p = 1 / (1 + e^(-0.6)) ≈ 0.646

이 예에서는 모델이 “이 제품이 불량일 확률은 약 64.6%”라고 예측한 것이다. 이 확률을 손실함수에 넣고, 손실이 작아지도록 w와 b를 조정한다.

경사하강법은 선형 모델에서만 쓰는가?

경사하강법은 선형 모델 전용이 아니라, 미분 가능한 손실함수를 가진 모델의 파라미터를 최적화하는 일반 방법이다.

SVM가능힌지 손실 또는 변형 손실을 최적화할 수 있다.

7. 모델 선택 예시

데이터 개수 100개, 변수 500개인 반도체 공정 데이터가 있다. 어떤 모델을 선택할 것인가?

이 문제는 모델 이름이 아니라 데이터의 조건을 보고 적절한 모델을 고르는 능력을 평가한다.

데이터 수가 적다100개뿐이므로 복잡한 모델은 과적합 위험이 크다.
변수 수가 많다500개 변수이므로 정규화와 변수 선택이 중요하다.
기준 모델이 필요하다로지스틱 회귀나 SVM으로 먼저 성능 기준을 잡는 것이 합리적이다.
선택 가능 모델선택 이유주의점
로지스틱 회귀기준 모델로 적합하고 해석이 비교적 쉽다.정규화와 변수 선택이 필요하다.
SVM작은 데이터와 고차원 변수에서 좋은 성능을 낼 수 있다.커널과 하이퍼파라미터 선택이 중요하다.
나이브 베이즈데이터가 적을 때 빠르게 기준 성능을 확인할 수 있다.독립성 가정이 실제와 다를 수 있다.
의사결정나무규칙을 해석하기 쉽다.데이터가 적고 변수가 많으면 과적합되기 쉽다.
KNN단순한 비교 모델로 사용할 수 있다.고차원에서는 거리의 의미가 약해질 수 있다.

9. 수업 정리

KNN가까운 데이터를 참고하는 거리 기반 모델이다.
선형회귀연속형 값을 예측하는 선형 모델이다.
로지스틱 회귀확률을 이용해 분류하는 선형 분류 모델이다.
나이브 베이즈베이즈 정리를 사용하는 확률 기반 모델이다.
의사결정나무조건문으로 데이터를 나누는 규칙 기반 모델이다.
SVM마진이 가장 큰 분류 경계를 찾는 마진 기반 모델이다.
경사하강법선형 모델 전용이 아니라 미분 가능한 손실함수를 최적화하는 일반 방법이다.
KNN, 회귀분석, 로지스틱 회귀, 나이브 베이즈, 의사결정나무, SVM으로 구분되는 이유는 각 모델이 데이터를 바라보는 관점과 예측을 만드는 원리가 다르기 때문이다.
