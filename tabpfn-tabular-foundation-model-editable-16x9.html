김임환 강의 자료1 / 28
One sentence

TabPFN은 “표 데이터를 위한 사전학습 Transformer”다

기존 ML

데이터마다 새로 학습

새 CSV가 들어오면 전처리, 모델 선택, 하이퍼파라미터 튜닝, 검증을 반복한다.

TabPFN

문제 푸는 법을 미리 학습

수많은 synthetic tabular task를 미리 학습하고, 새 데이터는 context로 넣는다.

핵심 변화

학습에서 추론으로 이동

새 데이터셋에서 긴 튜닝을 하지 않고 한 번의 forward pass로 예측한다.

강의에서 가장 쉬운 비유: GPT가 문장을 미리 공부하고 질문에 답하듯이, TabPFN은 표 데이터 문제를 미리 공부하고 새 Excel 문제를 푼다.
핵심 정의2 / 28
Why now

이미지와 텍스트는 딥러닝이 이겼지만, 표 데이터는 달랐다

현실의 의료, 금융, 제조, 마케팅 데이터는 대부분 표 형태인데, 이 영역은 오랫동안 Tree 기반 모델과 AutoML이 강했다.

배경 문제3 / 28
Why neural networks struggled

신경망이 표 데이터에서 자주 약해지는 이유

스케일 차이

0.001과 10,000,000이 같은 표 안에 섞인다. 숫자 크기가 곧 의미가 아닐 수 있다.

결측치

NaN, 빈칸, 측정 실패가 의미 있는 신호일 수도 있고 단순 오류일 수도 있다.

범주형 변수

True, Seoul, 장비 ID, Lot ID처럼 숫자가 아닌 값이 많다.

컬럼 의미

표의 각 열은 독립된 의미를 가진다. 이미지 픽셀처럼 주변 위치가 항상 중요하지 않다.

그래서 실무에서는 “딥러닝이면 다 좋다”가 아니라, XGBoost나 LightGBM이 여전히 강력한 기본 선택지였다.

기존 ML 파이프라인5 / 28
New idea

TabPFN의 질문: “모델을 다시 학습하지 말고, 학습 알고리즘 자체를 학습하면?”

기존 모델의 관점

새 데이터 D
→ 모델 f를 새로 학습
→ f(x)를 예측

데이터셋마다 학습 과정이 반복된다.

TabPFN의 관점

사전학습된 qθ
+ 학습 샘플 Dtrain
+ 테스트 샘플 xtest
→ ytest 확률

새 데이터에서는 gradient 기반 재학습 없이 예측한다.

메커니즘 29 / 28
Training once, using many times

사전학습은 한 번, 실전 예측은 빠르게

Offline 단계

1Synthetic dataset을 계속 샘플링한다.
2Transformer가 train subset을 보고 test label을 맞히도록 학습한다.
3학습된 weight가 추론 알고리즘 역할을 한다.

Online 단계

1새로운 실제 데이터셋의 train row를 넣는다.
2테스트 row를 함께 넣는다.
3한 번의 forward pass로 class 확률을 얻는다.

Performance claim

우수성 1: 짧은 시간에 강한 baseline 성능

원 논문은 작은 수치형 tabular benchmark에서 TabPFN이 빠른 시간 안에 튜닝된 Tree/AutoML과 경쟁적 성능을 보였다고 주장한다.

성능 메시지12 / 28
Why it can be strong

우수성 2: 작은 데이터에서 과적합을 줄이는 prior 효과

복잡한 튜닝 감소

작은 데이터에서 과도한 하이퍼파라미터 탐색은 validation split에 과적합될 수 있다.

분포 전체를 예측

단순 class label이 아니라 class probability를 출력하므로 불확실성 판단이 가능하다.

다양한 문제 경험

수많은 synthetic task로 “그럴듯한 표 데이터 구조”를 미리 경험한다.

교수자 관점에서 중요한 메시지: TabPFN의 강점은 마술이 아니라, 사전학습된 prior와 Bayesian inference 근사라는 설계 철학이다.
우수성의 원인13 / 28
Uncertainty

우수성 3: 점 예측보다 확률 판단에 가깝다

일반적 분류 결과

“이 샘플은 fail입니다.”

class = fail

의사결정에는 쉽지만, 얼마나 확신하는지는 별도 해석이 필요하다.

TabPFN식 결과

“fail일 확률이 높지만 불확실성이 있습니다.”

P(pass)=0.28
P(fail)=0.72

샘플 우선순위, 추가 측정, FA 의뢰 판단에 연결하기 쉽다.

확률적 해석14 / 28
But not magic

반드시 조심해야 할 한계

큰 데이터

원 논문은 주로 작은 데이터에 초점을 둔다. 대규모 실무 데이터에서는 별도 검증이 필요하다.

범주형 변수

범주형 feature가 많으면 Tree 모델이 여전히 더 실용적일 수 있다.

결측치

결측 자체가 중요한 제조 데이터에서는 처리 방식이 성능을 좌우한다.

불필요 변수

의미 없는 feature가 많으면 TabPFN 성능이 약해질 수 있다.

강의에서 과장 금지: TabPFN은 XGBoost의 종말이 아니라, 표 데이터에도 Foundation Model 방식이 들어왔다는 신호다.

Decision rule

실무 의사결정: 언제 TabPFN, 언제 XGBoost인가

상황우선 선택이유
샘플 수가 작고 빠른 결과가 필요TabPFN튜닝 없이 빠른 기준 성능을 얻기 쉽다.
수치형 feature 중심의 소규모 classificationTabPFN + XGBoost 비교논문상 TabPFN의 강점 영역이다.
대규모 생산 데이터, 수십만 행 이상XGBoost, LightGBM속도, 메모리, 배포 안정성이 검증되어 있다.
범주형, 결측, ID성 변수가 많음CatBoost, LightGBM해당 데이터 구조에 대한 현장 경험이 풍부하다.
설명 가능성과 감사 대응이 중요Tree + SHAP조직 내 설명과 승인 프로세스에 유리하다.

Lecture example

학생에게 줄 수 있는 실습 구조

1단계SECOM 데이터에서 target, is_synthetic, target_name을 구분하고 학습 feature를 정리한다.

수업 설계19 / 28
Evaluation

반도체 불량 예측에서는 Accuracy만 보면 안 된다

Accuracy

전체 정답률이다. 불량이 적으면 모두 양품이라고 해도 높게 나올 수 있다.

Recall

실제 fail 중 얼마나 찾아냈는가. 제조 불량 탐지에서는 특히 중요하다.

Precision

fail이라고 예측한 것 중 진짜 fail 비율이다. 불필요한 FA 비용과 연결된다.

의사결정 기준: “모델이 잘 맞췄는가”보다 “놓치면 안 되는 fail을 얼마나 잡았는가”를 먼저 본다.
평가 지표20 / 28
Teaching message

학생들에게 전달할 가장 중요한 관점

“TabPFN은 단순히 빠른 classifier가 아니다. 표 데이터 문제를 미리 학습한 foundation model이라는 점이 본질이다.”

ML 관점

모델을 고르는 시대에서, 사전학습된 추론기를 활용하는 시대로 이동한다.

반도체 관점

공정, 테스트, 결함, 수율 데이터를 하나의 tabular prediction 문제로 재구성할 수 있다.

전략 관점

빠른 baseline은 분석 시간을 줄이고, 엔지니어가 원인 해석에 더 많은 시간을 쓰게 한다.

강의 메시지21 / 28
Most likely objections

강의 중 나올 수 있는 반론과 답변

반론 1“XGBoost가 충분히 강한데 왜 필요한가?” 답변: 맞다. TabPFN은 대체재라기보다 빠른 강력 baseline이자 foundation model 패러다임의 예다.
반론 2“Synthetic data로 학습했는데 현실에 맞나?” 답변: 그래서 prior 설계가 핵심이며, 실제 데이터에서 반드시 비교 검증해야 한다.
반론 3“반도체 데이터는 크고 복잡하다.” 답변: 전체 원천 데이터를 그대로 넣기보다 문제를 작게 잘라 빠른 후보 검증에 쓰는 것이 현실적이다.

Final decision framework

수업의 결론: TabPFN을 이렇게 판단하라

무엇인가

표 데이터 문제를 미리 학습한 Transformer 기반 foundation model이다.

왜 중요한가

새 데이터마다 모델을 튜닝하는 기존 workflow를 줄일 가능성을 보여준다.

어떻게 써야 하나

소규모 수치형 classification에서 빠른 baseline으로 먼저 비교한다.

한 문장 결론: TabPFN은 XGBoost를 즉시 대체하는 모델이 아니라, 표 데이터 분석을 “사전학습 모델 시대”로 옮기는 중요한 전환점이다.

오늘 반영한 자료

ICLR 2023 TabPFN 원 논문, 오늘 대화에서 정리한 “누가 언제 왜 만들었는가”, 사용자가 올린 TabPFN 정형 데이터 Foundation Model 요약 자료를 통합했다.

강의 시 주의 문장

“TabPFN은 모든 데이터에서 최고”라고 말하지 않는다. “작은 표 데이터에서 매우 강력한 빠른 기준선이며, Foundation Model 패러다임의 실증 사례”라고 설명한다.
